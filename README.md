# Cuentas Claras MX

Calculadoras y guías gratis para cualquier persona en México. Sitio estático (HTML, CSS y JS sin dependencias), listo para GitHub Pages o Cloudflare Pages.

- `assets/calc.js`: cálculos y valores oficiales (salario mínimo, UMA). Actualizar cada año.
- `trabajo/`: aguinaldo, finiquito y liquidación, vacaciones.
- Pruebas: `node pruebas/calc.test.js`

Todas las rutas son relativas para que funcione también en `usuario.github.io/cuentas-claras-mx/`.
